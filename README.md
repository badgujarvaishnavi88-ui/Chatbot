# Python Chatbot

A simple chatbot application developed using Python that interacts with users and provides responses based on user input.

## Technologies Used

- Python

## Features

- User interaction through text input
- Responds to user queries
- Simple conversation flow
- Exit option for ending the chat

## Concepts Used

- Python Functions
- Conditional Statements
- Loops
- User Input
- String Handling

## Project Purpose

The purpose of this project is to understand Python logic building and create a basic conversational application using programming concepts.

## How to Run

1. Install Python
2. Download or clone the repository
3. Run the file:

```bash
python chatbot.py
